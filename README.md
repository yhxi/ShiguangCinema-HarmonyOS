# 时光影院 · HarmonyOS

时光影院（ShiguangCinema）的鸿蒙版本，界面与功能对齐 Android 版
[yhxi/ShiguangCinema-Android-TV](https://github.com/yhxi/ShiguangCinema-Android-TV)。

连接 LibreTV 服务端后即可搜索、点播、看直播，本地保存观看历史与收藏。
版本节奏与 Android 版同步：本包为 **1.5.5**，对应 Android TV v1.5.5 的功能面。

## 安装包

仓库根目录的 `ShiguangCinema-HarmonyOS-v1.5.5-unsigned.hap` 是**未签名**构建，
需要自行签名后才能装到设备上（见下方「签名」）。

- bundleName：`com.lshai.shiguangcinema`
- versionName：`1.5.5` / versionCode：`10155`（规则：`major*10000 + minor*100 + patch`）
- deviceTypes：`phone`

## 功能

- 首页：六个入口（点播 / 儿童 / 直播 / 搜索 / 收藏 / 设置，图标为矢量路径绘制，
  图标几何与 Android 版 `HomeIcons.kt` 逐条对应）、最近观看横向浏览最多 20 条、
  最新热门推荐（支持「混合 / 最新 / 热门 / 高分」榜单切换，失败静默重试且不打断已显示内容）
- 儿童乐园：3 个年龄分区（启蒙时光 / 探索世界 / 欢乐冒险）共约 100 部适龄动画，
  分区横向浏览；每日额度只统计**正在播放**的时间，默认 15 分钟、家长可设 1–240 分钟、
  可仅对当天加时；家长验证用大写数字乘法题；分季 / 番外 / 语言版本按同一部作品归一匹配；
  内置 82 部已核验封面（`rawfile/children_artwork.json`），未命中时用片名首字插画兜底
- 搜索：服务端聚合 + 直连采集源并行，失败自动回退；从儿童乐园或播放页「换源」进入时会提示来源
- 详情：选集、续播、收藏、加入儿童计时
- 播放：横屏、进度条、上下集、选集、倍速、画面比例、换源；
  点击画面中心暂停/继续，左右滑动调亮度/音量，水平滑动快进快退；
  普通返回保存进度并直接回首页，清晰度收进「更多」菜单
- 片头片尾：片尾标记按「距结束还有多久」记录（v1.5.2），同一部剧时长不同的剧集也能对准；
  当前集与记标记时的时长相差超过 max(30 秒, 25%) 时不再自动跳，旧标记按绝对位置兼容
- 播放失败自愈：换播放方式重试 → 同源重试一次 → 自动切换到有这部片的其他片源，
  全部失败才提示手动换源
- 直播：独立全屏直播播放器（上一台 / 下一台 / 选频道 / 音量 / 收藏，不写点播历史）；
  支持系统文件选择器导入 M3U/TXT 与粘贴导入；频道按「央视编号 → 地方台 → 其他」排序，
  同名频道作为备用线路依次尝试，默认播 CCTV1；收藏频道在列表置顶
- 片源管理：点播源启停/测速/订阅导入，直播源切换；内置点播源 21 个（与 Android 同步）
- 设置：片源管理、播放设置、电视直播、儿童时间管理、切换服务端、清理缓存、网络诊断
- 后台播放：开启后播放中申请音频持续任务并创建 AVSession
- 海报缓存：内存 LRU + 磁盘缓存，磁盘上限 200 MB（按字节计）

## 构建

需要 DevEco Studio 或 command-line-tools（含 HarmonyOS SDK）。

```powershell
$env:DEVECO_SDK_HOME='E:\Development\command-line-tools\sdk'
& 'E:\Development\command-line-tools\bin\hvigorw.bat' `
--mode module `
-p module=entry@default `
-p product=default `
-p buildMode=debug `
--no-daemon assembleHap
```

产物：`entry\build\default\outputs\default\entry-default-unsigned.hap`

也可以直接跑 `build-hap.cmd`（Windows）。

## 与 Android 版的差异

- 焦点体系与电视布局：Android 版面向遥控器（D-pad 焦点描边、自动聚焦）并支持 TV，
  鸿蒙包只声明 `phone`，触摸交互不需要焦点态；v1.5.3/v1.5.5 的「电视影院风 + 首页推荐轮播」
  属于 TV 分支，未移植；手机侧已采用 v1.5.5 的清新浅色海报墙与柔和浅绿入口。
- 检查更新：鸿蒙版从 GitHub Releases 下载未签名 HAP，需交给其他应用签名 / 安装。
- 崩溃日志：记录最近一次全局异常的类型和应用内位置，不保存原始消息或堆栈。
- 播放设置少 4 项：解码方式、缓存上限、起播缓冲、自动跳片头片尾——
  AVPlayer 没有对应 API，片头片尾也还没有全局开关字段。
- 儿童封面「长按从搜索结果指定」与同步到服务端（v1.3.5）：鸿蒙侧只有内置核验清单 + 片源兜底，
  尚未做手动指定。
- 全局搜索结果缓存（「只看可用源」、换源时的候选片源池）：鸿蒙侧未实现，
  播放页「换源」改为带片名跳搜索页重选。
- 边缘滑动返回：鸿蒙系统本身提供侧滑返回手势，未在应用内重复实现。
- 混合榜单的「部分榜单先显示」（v1.5.2）：鸿蒙侧仍是服务端一次返回后整体渲染。

## 变更记录

### v1.5.5（对应 Android v1.3.0–v1.5.5 的功能面）

- 新增儿童乐园：目录、每日额度、家长验证、封面索引、首页入口与详情页「加入儿童计时」。
- 直播重做：独立全屏播放器、本地 M3U/TXT 导入（文件选择器 + 粘贴）、频道排序、
  同名备用线路、收藏频道、默认 CCTV1、不写点播历史。
- 首页：六入口、最近观看横向 20 条并显示「第 N 集 · 已看 X%」（不足 1% 显示「刚开始看」）、
  「追剧」统一改「收藏」、「全部记录」改「全部历史」、推荐失败静默重试。
- 播放页：片尾按距结束时间判断并兼容旧标记、底部常驻「换源」、清晰度收进「更多」、
  普通返回直接回首页、儿童播放计时与到点暂停。
- 内置点播源补到 21 个；海报磁盘缓存改为按 200 MB 体积淘汰。
- 设置页移除顶部绿色连接状态大卡，新增「电视直播」「儿童时间管理」入口。
- 片源管理重做：状态筛选（全部/已启用/已停用/可用/不可用/内置/自定义）+ 搜索、
  6 并发批量测速并持久化健康记录（6 小时过期）、按可用性排序、批量启停、
  一键停用不可用、恢复内置源、删除二次确认。
- 缓存与加载：
  - 海报请求分「可见 / 预取」两条队列，可见请求插队，超时收紧到 3s 连接 / 7s 读取，
    清缓存时在途请求凭 generation 自我作废。
  - 儿童乐园、全部历史、收藏、直播分组、选频道列表改用 LazyForEach，只建屏幕上的行。
  - 详情页加 10 分钟内存缓存，返回再进直接复用并静默刷新。
  - 搜索页复用同关键词会话缓存，直连源并发从 4 提到 5。
  - 直播单组超过 48 个频道先折叠，其余点「展开其余 N 个」。
